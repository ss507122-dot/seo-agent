1. https://github.com/new → create repo `medzpalace-seo-agent` (private)
2. Upload ALL files from this folder (drag & drop in GitHub web UI)
3. https://railway.app → New Project → **Deploy from GitHub repo** → pick your repo
4. Variables tab → already set (Railway reads `.env` automatically) OR paste manually
5. Deploy → wait 2 min → logs show "Bot starting (long-poll)…"
6. Telegram me `@mywebsite_manager_bot` ko `/start` bhejein
